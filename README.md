# Spooky Diner Rush

A fast, level-based cooking game for the browser (Phaser + TypeScript + Vite).

```
npm install
npm run dev      # local dev server
npm test         # unit tests
npm run build    # typecheck + production build
```

Debug: add `?zones` to the URL (or press Z) to outline every station tap zone. In the game: B opens the Shop, R the Recipe Book, T the restaurant list (or use the round buttons at the top right). `?debug&level=N&speed=N` jumps to a level and speeds up time.

Docs: `docs/style-guide.md`, `docs/architecture.md`, `docs/progress.md`.
