# Android app (Capacitor)

The Android app is the same game in a native WebView. The web files come from a separate build, `npm run build:android` (folder `dist-android`, git-ignored). It is the normal build with ONE difference: the CrazyGames SDK script is removed, so CrazyGames code can never run inside the app (ads in the app will be Google AdMob, added in a later step; until then the app shows no ads and no rewarded button). The intro video stays.

## What is in the repo
- `capacitor.config.ts`: app name, `appId` (PROVISIONAL, `com.spookydinerrush.game`; it cannot change after the first store upload), web folder `dist-android`.
- `android/`: the generated Android Studio project. Edited by hand: `AndroidManifest.xml` (`sensorLandscape`), `MainActivity.java` (full screen, notch, no overscroll). The copied web files inside `android/app/src/main/assets/` are generated by `cap sync` and git-ignored.
- `src/platform/android.ts` and `androidLogic.ts`: app pause and resume, and the Back button. Only the Android build contains them (and the Capacitor files).

## Build a debug APK (you, on your computer)
One-time setup: install Android Studio (it brings the Android SDK and a JDK). Node 22 or newer.
1. `npm ci`
2. `npm run android:sync` (builds `dist-android`, copies it into the Android project)
3. Easiest: `npm run android:open`, wait for Gradle to finish, then in Android Studio use Build > Build Bundle(s) / APK(s) > Build APK(s). Or from the terminal: `cd android` then `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).
4. The file is `android/app/build/outputs/apk/debug/app-debug.apk`. To install: copy it to the phone and open it (allow "install unknown apps"), or with USB debugging on: `adb install -r app/build/outputs/apk/debug/app-debug.apk` (run from the `android` folder, path `app/build/outputs/apk/debug/app-debug.apk`).
After changing game code, run `npm run android:sync` again before rebuilding.
A debug APK is for testing only. The signed release build and the store checklist come in the release-prep step. Never commit a keystore or `local.properties`.

## Behaviour (what the code does; device test still needed)
- Landscape only (`sensorLandscape`, both landscape directions), full screen with the system bars hidden (swipe from the edge shows them briefly).
- Home, app switcher or lock screen: the game saves, pauses (the Paused screen shows) and the sound stops. Coming back restarts sound but keeps the Paused screen until you tap Resume.
- Back button: closes Shop, Recipe Book or the restaurant list; otherwise pauses the game; on the title, Paused or Closed screen it sends the app to the background. It never quits the game and never reloads the page.
- No orientation or fullscreen web code runs in the app (the browser version still uses it).
